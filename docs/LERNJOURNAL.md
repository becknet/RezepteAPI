## Empfohlene Themen zum Aufarbeiten der vollständigen App

1. **Oberfläche verstehen (E5–E7):** Skizziere die Ansichten. Begründe Anordnung, Farben, Komponenten und mobile Anpassung. Zeige den Unterschied zwischen Bootstrap und eigenem CSS.
2. **Formulare und Validierung (E1/E2):** Erzeuge mindestens drei unterschiedliche Fehlerfälle. Erkläre jede Prüfbedingung und ändere zum Verständnis eine Regel mit passendem Test.
3. **API und JSON (E3/E4):** Dokumentiere eine echte Anfrage und Antwort im Netzwerk-Tab. Verfolge eine Zutat vom Eingabefeld bis zur Rezeptkarte. Erkläre CORS und HTTP-Fehler.
4. **Vergleich und Interaktion (E4/E8):** Rechne ein kleines Beispiel von Hand nach. Erkläre ODER-Kandidaten, Sortierung, Grenze von 60 und fehlende Mengenerkennung.
5. **Speicherung und Qualität (E8/E9):** Zeige Persistenz und Fehlerbehandlung. Unterscheide automatisierte und manuelle Nachweise. Dokumentiere eine eigene Verbesserung.
6. **Veröffentlichung (E10):** Dokumentiere Repository, erfolgreichen Action-Lauf, öffentliche URL und Prüfung des veröffentlichten Stands.

## Selbsteinschätzung

Für jede Kompetenz E1–E10: Kann ich sie am Code zeigen und ohne Vorlesen erklären? Welcher konkrete Beleg fehlt noch?

## Schlussreflexion

Was habe ich gelernt? Wo war ich von Hilfe abhängig? Welche technische Entscheidung würde ich heute anders treffen? Welche nächste Funktion kann ich selbstständig umsetzen?
